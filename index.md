  <p>I'm Shubham, an RTL design engineer focused on CPU microarchitecture, digital datapaths, FPGA implementation, and SoC IP integration. I take logic from specification to silicon — working across timing closure, clock domain crossing, power optimization, and static timing analysis.</p>

  <p>I'm currently a graduate researcher at Arizona State University, building a runtime-adaptive cache compression framework for RISC-V. The system profiles ML workload memory-access behavior using Intel Pin, models compressibility patterns, and selects among FPC, BDI, FVC, and ZCA schemes dynamically — reaching a 10% cache-miss reduction and 1.2x–1.8x effective cache-capacity improvement on CNN, K-means, DBSCAN, PCA, SQLite3, and STREAM benchmarks.</p>

  <p>Before graduate school, I was an RTL design engineer at Manjeera Digital Systems, where I designed IEEE-754 floating-point datapath blocks and 20 vector instructions for an AI-accelerator DSP core targeting NavIC satellite signal processing, improved SoC Fmax from 640 MHz to 800 MHz, and reduced dynamic power by 23% through pipeline rebalancing and clock gating. I started as an FPGA design intern at OneRupeeST, building a DMA block with AXI register interface, FSM control logic, and directed testbenches.</p>
